# AWS Highly Available Web Architecture (Multi-AZ)

## (ENG) Overview

This project demonstrates the design and implementation of a highly available and secure web architecture on AWS, focused on:

- Network isolation (VPC segmentation)
- Multi-AZ deployment
- Controlled internet access
- Load balancing with ALB

The goal is to simulate a production-like environment using AWS best practices for scalability, security, and resilience.

## (ESP) Descripción

Este proyecto demuestra el diseño e implementación de una arquitectura web altamente disponible y segura en AWS, enfocada en:

- Aislamiento de red (segmentación de VPC)
- Despliegue multi-AZ
- Acceso controlado a internet
- Balanceo de carga con ALB

El objetivo es simular un entorno cercano a producción aplicando buenas prácticas de AWS en escalabilidad, seguridad y resiliencia.
